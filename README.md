# 车站无障碍通道 · 暴雨倒灌复核器

纯浏览器运行的复核工具：审核员在最多 **20×20** 的站厅网格中编辑阻断（淹水封闭）格、
通行格（进入耗时 1–99 秒）和电梯格（组号 1–9、首次等待 1–99 秒），点选起点、终点与
**北 / 东 / 南 / 西** 初始朝向，求解在暴雨封闭后的最优无障碍路线。

- 仅 TypeScript + React 18 + Vite，**不调用任何在线服务，也没有业务后端**；构建产物是纯静态文件。
- 最短路在 Web Worker 中计算，求解期间页面仍可点击、编辑、滚动。

## 计费规则

1. **相邻正交移动**（北/东/南/西）：基础耗时 = 目标格的耗时；若朝向发生改变，另加 **5 秒** 转弯费。
2. **同组电梯换乘**：从某部电梯可一步到达同组任意另一部电梯，固定 **8 秒**，**朝向不变**；
   每个电梯组的**首次乘用**额外加收一次该组的“首次等待”秒数，同组重复乘用不再收取。
3. 走入电梯格本身按普通正交移动计其基础耗时，不触发等待；只有“换乘”才收 8 秒与等待。

## 优化目标（逐级字典序）

依次最小化：

1. 路线总秒数；
2. 转弯次数；
3. 从起点起逐项比较的 `(行号, 列号)` 坐标序列（行优先字典序，取较小者）。

求解状态为 `(位置, 朝向, 已付费电梯组集合)`，采用带可采纳且一致启发函数的 **A\***
（反向“忽略朝向/等待”的最短秒数作为下界），三级标签比较在一棵不可变标签树上用
LCA（倍增）完成，最坏情形（20×20、九组电梯、昂贵瓶颈通道）仍为毫秒级。

## 不可达与失败证据

封闭后若终点不可达，旧路线立即消失，并在网格上描出**从起点可达的格**（连通关系与求解器
完全一致：正交非阻断相邻 + 同组电梯）。证据分三类列出，可逐格核对：

- 真正阻断（淹水封闭）格数；
- 从起点可达的开放格数；
- 与起点不连通的**其它开放片区**格数——这些格并未淹水，只是被阻断格隔开，终点位于其中。

校验非法时（尺寸、耗时、等待越界，组号非法，同组等待不一致，起点/终点落在阻断格等），
顶部给出带行列定位的清单、问题格红框标注，结果清空且禁止求解。

## 本地运行（Node 20）

```bash
npm install
npm run dev        # 开发服务器（Vite，默认 http://localhost:5173）
npm run build      # 类型检查 + 产出 dist/
npm run preview    # 本地预览构建产物
```

## Docker Compose

```bash
# 启动可用页面（宿主默认端口 8080）
docker compose up --build
# 浏览器打开 http://localhost:8080

# 用 WEB_PORT 覆盖宿主端口
WEB_PORT=9000 docker compose up --build

# 一次性验收：类型检查 + Vitest + Playwright，跑完即退出
docker compose run --rm verify
```

- `web` 服务为 nginx 托管的纯静态页面，容器内监听 80，映射到宿主 `${WEB_PORT:-8080}`。
- `verify` 是**一次性**服务（`restart: "no"`，不监听端口），使用内置 Chromium 的
  Playwright 镜像，自动构建并起临时 preview 完成端到端验收，结束后容器退出。

## 测试

```bash
npm test           # Vitest：手算用例、逐步账目重放、随机差分（Dijkstra 对独立 SPFA）、
                   # 3×3 全路径 DFS 穷举交叉验证、字段定位、不可达证据、20×20 性能
npm run e2e        # Playwright：求解展示、字典序择优、非法字段清空、点选、不可达证据
npm run verify     # tsc --noEmit && vitest run && playwright test
```

## 目录结构

```
src/
  types.ts          领域模型、状态、费用常量
  solver.ts         A* 求解器 + 不可变标签树 + 洪水可达证据
  solver.worker.ts  Web Worker 入口
  useSolver.ts      主线程 Worker Hook（旧请求自动作废，含同步兜底）
  validation.ts     编辑文档解析与逐字段定位校验
  presets.ts        暴雨倒灌 / 纯步行示例
  components/       棋盘、格编辑器、路线明细表
  App.tsx           编辑、点选、求解编排与结果清空
e2e/app.spec.ts     Playwright 交互测试
```
